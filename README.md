# AMA Global Marketing SIG Website

This repository contains the source code for the official website of the [AMA Global Marketing Special Interest Group (SIG)](https://amaglobalsig.netlify.app/). 

The AMA Global Marketing SIG connects international marketing scholars, practitioners, and doctoral students worldwide through annual conferences, research awards, and collaborative programs.

## Live Website
[https://amaglobalsig.netlify.app/](https://amaglobalsig.netlify.app/)

## Tech Stack
- **Framework:** Astro
- **Content:** MDX
- **Deployment:** Netlify

## Content Structure
- **Mission & Leadership:** Board of directors, governance, and history.
- **Events:** Annual global conferences (e.g., Osaka 2027) and doctoral consortia.
- **Awards:** Significant Contributions, Excellence in Research, Hans B. Thorelli Award, and S. Tamer Cavusgil Award.
